# Form

[← Modules](./Modules.md)

## How this module thinks

Form does not decide *what the subject is*. It decides **what kind of physical logic that subject obeys**.

It can make a person compact or elongated, turn typography into inflated ribbon-like structures, make a scene crystalline and terraced, or push an animal into a segmented armored silhouette. This is the module for shape grammar, proportion, and deliberate deformation.

## Recipes

### Identity-preserving designer toy

**Goal:** turn a person into a compact toy without replacing their visual identity.

**Use:**
- Form Language → Soft Rounded
- Proportions → Oversized Head
- Transformation → Custom: “compress facial depth slightly while preserving recognizable feature placement”
- Strength → Moderate
- Style → Vinyl Toy
- Texture → Vinyl

**Why it works:** Form handles geometry while Style and Material handle appearance.

### Inflated architectural typography

**Use:**
- Subject Type → Typography
- Form Language → Inflated Letterforms
- Proportions → Tall / Narrow
- Transformation → Type Inflate
- Strength → Strong
- Extra Details → “keep counters readable and treat strokes like connected pneumatic tubes”

**Why it works:** typography remains typography, but its physical logic is explicitly transformed.

### Alien landscape that still reads as terrain

**Use:**
- Subject Type → Scene
- Form Language → Stratified Environment
- Proportions → Broad Horizontal
- Transformation → Crystalline Growth
- Strength → Strong

**Why it works:** subject-aware form choices push the environment instead of accidentally describing character anatomy.
