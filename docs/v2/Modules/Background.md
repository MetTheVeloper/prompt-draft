# Background

[← Modules](./Modules.md)

## How this module thinks

Background builds the **world or backing surface behind the subject**. It can be a literal environment, a studio sweep, a material plane, a graphic pattern, an abstract construction, or transparent output.

The module separates concept, setting, structure, material, density, and optional elements so “background” does not have to be one giant sentence.

## Recipes

### Product shot that feels architectural

**Use:**
- Preset → Material Background
- Type → Surface
- Structure → Custom: “two intersecting stepped planes forming a shallow architectural plinth”
- Material → Concrete
- Density → Minimal

**Why it works:** the background stays physically simple while its spatial construction becomes specific.

### Fake children’s-TV set

**Use:**
- Concept → Studio Background
- Setting → Performance / Stage
- Structure → Framed
- Material → Custom: “painted plywood flats with visible handcrafted seams”
- Elements → Custom: “oversized cardboard clouds and simplified shrubs”

**Why it works:** several small custom values extend the catalog without replacing the Background grammar.

### Transparent product asset

**Use:**
- Preset → Transparent Background
- Keep Framing/Lighting active for how the subject itself is presented

**Why it works:** “transparent” is scoped to the background rather than being confused with transparent object material.
