```text

-> HTTP 200

-> repeated tags use OR/union semantics
```

Limit validation:

```text

-> HTTP 400

```

### Public Prompt Archive list access

The temporary test-era auth/email gate on the `/prompts` list was removed during 21D verification.

Current boundary:

```text
/prompts list + filters + cards + preview media
  -> public / anonymous allowed

GET /api/archive
  -> public list endpoint

/prompts?id=<id> full detail
GET /api/archive/:id
  -> authenticated user + email still required
```

This keeps public discovery useful without opening full Prompt bodies/variants.

### Rendering evidence gate

Nuxt correctly reported the existing SPA limitation:

```text
HTML content not prerendered because ssr: false was set.
```

This activated the ADR-001 evidence gate.

Rather than migrate the entire app to SSR, 21D introduced build-time public SEO enrichment for the six `/discover/*` routes after `nuxt generate`.

The post-generation script was then run against the generated static artifact and verified to enrich all six discovery routes with sanitized data:


## Final rendering decision

21D does **not** require a full SSR migration.

Current accepted architecture remains:

```text
Nuxt ssr:false
pnpm generate
static frontend artifact
independent Node API
post-generate sanitized SEO enrichment for controlled public acquisition routes
```

This is sufficient for the current six discovery routes and present catalog scale.

ADR-001 remains active for future migration triggers such as:

```text
large public page volume
build-time pressure
faster Creator publishing/indexing freshness requirements
future public Product/Creator page scale
hosting support for hybrid/incremental rendering
```

## Security/content boundary after 21D

Public:

```text
Archive list presentation
/discover/* category pages
sanitized public discovery projection
preview media
titles/tags/published date
creator attribution only when authoritative
```

Protected:

```text
full Prompt body
variants
private Draft data
non-public account data
moderation/admin state
```

Historical `public/data/prompts.json` remains a known architectural cleanup concern and must not be treated as the canonical future public SEO projection.

## Result

Milestone 21D is **DONE / LOCALLY VERIFIED / USER ACCEPTED**.

The project now has a real public acquisition/indexing foundation without replacing the existing static deployment architecture or widening protected Prompt-content semantics.
