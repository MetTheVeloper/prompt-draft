# گزارش امکانات صفحه Collage

این سند یک توضیح کوتاه و محصول‌محور از وضعیت فعلی صفحه `collage.vue` است. هدف این فایل این است که خیلی سریع مشخص کند صفحه کلاژ الان چه امکاناتی دارد و کاربر نهایی با چه ابزاری روبه‌رو است.

---

## خلاصه کلی

صفحه Collage در حال حاضر یک ویرایشگر کلاژ تصویر است که می‌تواند مجموعه‌ای از تصاویر را دریافت کند، بر اساس نسبت ابعاد آن‌ها یک چیدمان مناسب بسازد، امکان کنترل خروجی، جابه‌جایی دید، منوی کلیک راست، مدیریت سلول‌ها، تصویر در تصویر، برندینگ و خروجی گرفتن را فراهم کند.

این صفحه دیگر صرفاً یک ابزار ساده چسباندن عکس‌ها نیست؛ بلکه یک محیط canvas-based کوچک برای ساخت خروجی‌های تصویری از تصاویر تولیدشده با پرامپت است.

---

## ورودی تصویر

امکانات فعلی ورودی تصویر:

- انتخاب چند تصویر از فایل‌سیستم
- drag & drop تصویر روی workspace
- paste مستقیم تصویر از clipboard
- حذف همه تصاویر
- حذف یک تصویر انتخاب‌شده
- جایگزینی تصویر یک سلول
- empty state واضح برای شروع کار با CTA افزودن تصویر

در حالت empty state، خود canvas نمایش داده نمی‌شود و کاربر یک کارت راهنما برای افزودن تصویر می‌بیند.

---

## چیدمان هوشمند کلاژ

سیستم کلاژ به صورت خودکار بر اساس نسبت تصاویر، ترکیب‌های مختلف layout را بررسی می‌کند و مناسب‌ترین چیدمان را انتخاب می‌کند.

امکانات مرتبط:

- ساخت layout خودکار بر اساس نسبت تصاویر
- حالت الگوریتم `controlled` و `free`
- شافل عکس‌های هم‌نسبت بدون تغییر فرم layout
- شافل کامل layout برای ساخت ترکیب تازه
- قفل کردن نسبت canvas خروجی

نسبت‌های خروجی قابل انتخاب:

- Auto
- 1:1
- 16:9
- 9:16
- 2:1
- 3:2
- 3:1
- 3:7

---

## کنترل canvas و خروجی

در بخش Canvas، کاربر می‌تواند ظاهر و اندازه خروجی را کنترل کند.

امکانات:

- انتخاب اندازه خروجی:
  - Small = 800
  - Medium = 1200
  - Large = 2048
- کنترل کیفیت خروجی از 30 تا 100
- فعال/غیرفعال کردن decorationهای canvas
- تنظیم inner padding
- تنظیم image gap
- تنظیم radius گوشه سلول‌ها
- تنظیم background color

وقتی decoration غیرفعال باشد، padding، gap، radius و background از خروجی بی‌اثر می‌شوند و سلول‌ها بدون فاصله کنار هم قرار می‌گیرند.

---

## Navigation و دید canvas

workspace کلاژ از zoom و pan پشتیبانی می‌کند.

امکانات:

- zoom با wheel ماوس روی نقطه cursor
- pan با middle mouse drag
- ابزار hand / pan tool برای pan با left drag
- reset/fit view هنگام تغییر معنی‌دار تصاویر
- جلوگیری از اجرای selection هنگام pan
- هماهنگی selected-cell overlay با zoom و pan

این رفتار باعث می‌شود canvas حتی در زوم‌های بالا قابل پیمایش و کنترل باشد.

---

## انتخاب و مدیریت سلول‌ها

هر سلول canvas قابل تشخیص و انتخاب است.

رفتارها:

- single click روی سلول: select / deselect
- double click روی سلول: toggle بین Cover و Detail
- right click روی سلول: باز کردن منوی اختصاصی سلول
- arrow keys برای pan تصویر انتخاب‌شده در حالت Detail
- Shift + Arrow برای pan سریع‌تر

سلول انتخاب‌شده با یک overlay فقط مخصوص UI نمایش داده می‌شود و این overlay وارد خروجی export نمی‌شود.

---

## حالت Cover / Detail و Pan تصویر

هر تصویر داخل سلول می‌تواند در دو حالت نمایش داده شود:

- Cover: رفتار کلاسیک cover، یعنی تصویر سلول را پر می‌کند.
- Detail: تصویر با scale نزدیک‌تر به اندازه واقعی خودش نمایش داده می‌شود تا جزئیات بیشتری دیده شود.

در حالت Detail، تصویر داخل سلول قابل pan است. Pan هم با drag و هم با keyboard انجام می‌شود.

---

## PIP یا تصویر در تصویر

هر سلول می‌تواند یک تصویر کوچک جداگانه به عنوان PIP داشته باشد. این قابلیت برای نمایش تصویر اصلی/reference روی خروجی تبدیل‌شده بسیار مناسب است.

امکانات PIP:

- انتخاب PIP برای هر تصویر
- جایگزینی PIP
- حذف PIP
- انتخاب اندازه:
  - Small
  - Medium
  - Large
- انتخاب موقعیت:
  - top-left
  - top-center
  - top-right
  - center-left
  - center-right
  - bottom-left
  - bottom-center
  - bottom-right

ویژگی‌های ظاهری PIP:

- همیشه مربع است.
- تصویر داخل مربع با cover نمایش داده می‌شود.
- radius نرم دارد.
- shadow و border سبک دارد.
- داخل canvas رندر می‌شود، بنابراین در export تصویر نهایی دیده می‌شود.

## منوی کلیک راست

صفحه Collage چند سطح context menu دارد.

### منوی پیش‌فرض صفحه

برای کلیک راست عمومی صفحه:

- Save
- Copy
- Clear
- Refresh

### منوی فضای خالی workspace / wrapper

برای کلیک راست روی فضای خالی canvas workspace:

- Add image
- Shuffle images
- Shuffle layout
- Controlled / Free
- Toggle pan tool
- Toggle image/video mode
- Save
- Copy
- Clear

### منوی سلول

برای کلیک راست روی یک سلول:

- Replace image
- Select / Replace PIP
- Cover / Detail
- Reset position
- Remove image

این منو با کامپوننت اختصاصی ساخته شده و به جای لیست بلند، UI فشرده‌تری دارد.

### منوی PIP

برای کلیک راست روی خود تصویر PIP:

- Replace PIP
- Remove PIP
- انتخاب اندازه
- انتخاب موقعیت با آیکون‌های داینامیک

منوی PIP فقط گزینه‌های مخصوص PIP را نشان می‌دهد و گزینه‌های عمومی یا سلول را نمایش نمی‌دهد.

## Brand

سیستم برندینگ از دو حالت پشتیبانی می‌کند:

### Disabled

اگر brand غیرفعال باشد، هیچ متن، لوگو یا QR روی خروجی اضافه نمی‌شود.

### Overlay

در این حالت، برند مثل قبل روی خود تصویر کلاژ قرار می‌گیرد و ابعاد canvas را تغییر نمی‌دهد.

### Footer

در این حالت، یک نوار مستطیلی جدا پایین خروجی اضافه می‌شود.

ویژگی‌های Footer:

- رنگ footer از background فعلی canvas گرفته می‌شود.
- padding مستقل دارد.
- align مستقل دارد: left / center / right
- نسبت خروجی در حالت locked ratio روی کل تصویر نهایی اعمال می‌شود.
- وقتی footer فعال است، padding پایین بخش کلاژ صفر می‌شود تا فاصله اضافی بین سلول‌ها و محتوای footer ایجاد نشود.

فعلاً Brand Footer فقط برای image mode پیاده‌سازی شده است.

## پنل کناری و responsive UX

پنل تنظیمات قابل dock / floating است.

امکانات:

- switch کنار عنوان Collage Builder برای dock/floating
- دکمه باز و بسته کردن پنل در canvas options
- وقتی پنل dock نباشد، روی main box نمایش داده می‌شود.
- وقتی پنل dock باشد، در کنار canvas options قرار می‌گیرد.
- workspace می‌تواند فضای بیشتری بگیرد، مخصوصاً برای حالت موبایل یا صفحه‌های کوچک.

---

## ذخیره تنظیمات

بخشی از تنظیمات editor در localStorage ذخیره می‌شود تا بعد از refresh هم حفظ شود.

نمونه تنظیمات ذخیره‌شونده:

- mode تصویر/ویدئو
- brand enabled
- brand mode
- padding / gap / radius
- background color
- decorations enabled
- layout constraint mode
- canvas ratio
- output size
- export quality
- panel dock/visible state

---

## خروجی گرفتن

امکانات خروجی تصویر:

- Save image
- Copy image
- export quality بین 30 تا 100
- خروجی با اندازه قابل انتخاب 800 / 1200 / 2048

وقتی quality روی 100 باشد، رفتار خروجی با کیفیت کامل حفظ می‌شود. در کیفیت‌های پایین‌تر خروجی برای حجم کمتر فشرده‌تر می‌شود.

---

## وضعیت ویدئو

صفحه همچنان mode ویدئو دارد، اما بعضی از قابلیت‌های جدید مثل PIP و Brand Footer فعلاً فقط برای image mode کامل شده‌اند. تصمیم فعلی این است که اول قابلیت‌ها در image mode کامل و پایدار شوند و بعد در مرحله جداگانه به video preview/export منتقل شوند.

---

## جمع‌بندی

Collage در وضعیت فعلی یک editor کامل برای ساخت خروجی‌های تصویری از تصاویر prompt-based است. تمرکز اصلی آن روی کنترل دقیق layout، خروجی، برندینگ، انتخاب سلول، تصویر در تصویر و UX سریع با shortcut و context menu است.
